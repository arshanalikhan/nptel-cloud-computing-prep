# NPTEL Cloud Computing Prep

A one-page study kit for the NPTEL **Cloud Computing** course (IIT Kharagpur, Prof. Soumya Kanti Ghosh, noc26_cs150, exam on 18 Oct 2026).

**Live site:** https://arshanalikhan.github.io/nptel-cloud-computing-prep/

## What's inside

- **3-day plan** for the last days before the exam
- **Formula sheet** for the numericals that come up every run (SLA availability, cloud vs owning cost, HDFS blocks, VM migration time, OpenStack overcommit, PUE)
- **Week-by-week notes** for all 12 weeks, with links to every official lecture video
- **Most repeated questions**: 48 ideas ranked by how many course runs asked them (2019–2026)
- **Practice bank**: 361 questions, filterable by week, with explanations
- **Mock exams**: five timed 50-question papers with a score breakdown and review
- **Light and dark mode**, with your choice remembered

Everything runs in the browser; your answers and scores are stored only in your own browser.

## Notes

This is an unofficial study aid, not an NPTEL product. NPTEL does not publish past proctored exam papers, so the practice questions are reworded from past weekly assignments. Check the official course page for exam rules: https://onlinecourses.nptel.ac.in/noc26_cs150
